# Демо-сценарий для комиссии (3 минуты)

Подготовка (до доклада): сервер запущен (`docker compose up -d` или `cargo run -p popproto-server`), открыты **три вкладки** браузера с игрой + вкладка с репозиторием на GitHub. Звук включён.

---

## 0:00–0:20 — Вход и лобби
- В первой вкладке: ввести ник → «Играть». Показать список комнат, палитру цветов (клик по цвету — ракетка перекрасилась).
- Создать комнату «Демо», показать код комнаты.

## 0:20–0:50 — Мультиплеер и боты
- Во второй вкладке войти по коду комнаты. Показать: ready-чек, оба игрока готовы.
- Добавить бота «+ Профи» → кнопка «Старт».
- **Пока матч грузится сказать:** «Сервер ведёт физику на 30 герцах, клиент рисует 60 кадров — траектории сглаживает кубическая интерполяция».

## 0:50–1:30 — Геймплей
- Играть самому (мышь = ракетка, клик = запуск). Показать: стеклянные кирпичи с трещинами, частицы, шлейф мяча.
- Довести комбо до ×5 → **фейерверк** на экране («награда за серию»).
- Поймать капсулу (лазер/широкая ракетка).
- Если начнётся событие — прокомментировать плашку («события меняют правила каждые 45–75 секунд»).

## 1:30–2:00 — Реконнект (главный технический трюк)
- В первой вкладке нажать **F5** посреди матча.
- Страница перезагрузилась → автоматически вернулась в матч: счёт, жизни, **полная сетка кирпичей** на месте.
- «Соединение держит слот 90 секунд, ракетку всё это время ведёт бот, возврат — по токену без пароля».

## 2:00–2:30 — Код и нагрузка
- Переключиться на вкладку GitHub: README с архитектурой, зелёный CI-бейдж.
- Открыть docs/PERFORMANCE.md: «тик матча — 4,8 микросекунды при бюджете 33 миллисекунды; 500 одновременных игроков — 17 % одного ядра, 20 мегабайт памяти».

## 2:30–3:00 — Финал
- Вернуться в игру: показать босса (если успели до 3-го уровня — упомянуть скриншотом на слайде).
- «Всё это — 82 юнит-теста, CI, Docker-деплой. Играть можно прямо сейчас по ссылке».

---
